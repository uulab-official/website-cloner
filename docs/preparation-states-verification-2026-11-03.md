## 사용법과 한계

[prepare:clone 가이드](prepare-clone.md)의 상태 준비 예제를 참고한다. 한 번에 한 상태이며 추가 상태는 새 폴더를 쓴다. 클릭/스크롤은 사용자가 명시한 비파괴적 관찰 용도로만 제공하며 구매·로그인·문의 제출·삭제 동작을 넣으면 안 된다. 선택자 사전 발견, 임의 JavaScript 실행, 자산 다운로드, 앱 생성, 동작 의미의 자동 판정은 추가하지 않았다. source 동작/스크립트의 네트워크 부작용을 차단하는 샌드박스는 아니다. targetVisited는 별도 target 캡처를 수행하지 않았다는 기록이지 모든 간접 요청이 없다는 보장은 아니다.

실제 Safari·물리 휴대폰·터치·macOS/Windows 실행·백엔드·전체 모션은 미검증이다. 입력 해시는 출처 진위를 인증하지 않으며 적대적 동시 파일 변경을 격리하지 않는다. URL·페이지·로그의 민감정보를 공유 전에 검토해야 한다.
