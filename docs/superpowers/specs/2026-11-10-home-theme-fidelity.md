# Homepage theme fidelity

Continue the authored homepage at /home/ rather than recreating it. Keep / and /services/ as the existing service routes. Compare the owned source https://uulab.co.kr/ against the production /home/ with matching Chromium, Firefox and WebKit sessions, including explicit site theme toggles. Preferred color-scheme alone is not proof of the site's active theme.

Observe light and dark top, menu and question-region states before changing CSS. Ground repairs in measured computed styles and preserve static content, assets, dependencies, source attribution and intentional accessible menu/footer differences. Separate changed live content from renderer defects. Add deterministic regression tests before any CSS fix. Do not copy production JavaScript or stylesheets. No new server, tracking, forms, payment, downloads of reusable assets or font distribution.

Record exact commands, actual engine versions, fresh capture dates and screenshots. Keep comparison completion separate from a visual pass and from functional parity. Full-height dimension mismatches are preserved, not resized away. No claim of physical devices, branded Safari, backend or complete motion equivalence.
