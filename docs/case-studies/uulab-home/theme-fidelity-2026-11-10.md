## 재현

```bash
npm ci
npx playwright install chromium firefox webkit
npm run check
npm run check:browsers -- --out artifacts/home-browser-check
npm run build

```

다른 터미널에서 선택한 엔진으로 원본과 구현을 새로 비교한다.

```bash
npm run verify:suite -- --manifest suites/uulab-home-dark.json --browser chromium --out artifacts/home-dark-chromium
npm run verify:suite -- --manifest suites/uulab-home-dark.json --browser firefox --out artifacts/home-dark-firefox
npm run verify:suite -- --manifest suites/uulab-home-dark.json --browser webkit --out artifacts/home-dark-webkit
```

실행 결과는 캡처 시점의 사이트·브라우저·글꼴·운영체제에 따라 달라질 수 있다. 작성자가 변경 diff·40개 색상 계약·회귀 검사·세 엔진 비교 이미지를 자체 검토했으며 독립 코드 리뷰는 받지 않았다. 실제 macOS Safari·물리 휴대폰·터치·전체 애니메이션·백엔드 동등성은 미검증이다. Linux Playwright WebKit을 실제 Safari 검증으로 표시하지 않는다.
