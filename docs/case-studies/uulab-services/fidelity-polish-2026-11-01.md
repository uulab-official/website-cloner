- 테마/메뉴 컨트롤의 포커스 테두리와 간격을 관찰값에 맞췄다. 키보드 사용도 유지한다.

가독성을 위해 원본과 다르게 유지한 부분은 **불투명 메뉴 배경, 더 밝은 다크 모드 달 아이콘, 하단 링크 줄바꿈**이다. 따라서 정확한 픽셀 복제를 완료했다고 주장하지 않는다.

### 중요: 0%는 픽셀 동일성을 뜻하지 않는다

현재 compare는 `pixelmatchThreshold: 0.1`, `includeAntiAliasing: false`를 사용한다. 작은 색상 차이와 안티앨리어싱 차이를 무시할 수 있으므로 **0%를 동일 이미지라고 표현하면 잘못이다**.

새 메뉴 side-by-side를 직접 열면 왼쪽 원본은 뒤 본문이 비치고 오른쪽 구현은 불투명하다. 이 가시적 차이가 있어도 기본 비교기 결과는 0%다. PNG를 RGBA로 디코딩하고 허용 오차/안티앨리어싱 제외 없이 어느 채널이든 다른 픽셀을 세면 **122,805 / 351,000 = 34.9871794872%**다. 이것도 의미 품질 점수는 아니다. 약한 배경색 차이가 넓은 영역에 퍼져 있어 두 방식이 크게 달라진다. 이번에 비교기의 허용 오차를 바꿔 수치를 좋게 만들지 않았다.

메뉴·다크·FAQ·짧은 화면 PNG를 눈으로 검토했다. 다크 모드의 달 아이콘 밝기는 의도적으로 다르다. FAQ는 양쪽 모두 열렸지만 원본은 해당 스크롤 상태에서 헤더가 숨겨지고 구현은 고정 헤더를 유지한다. summary 포커스 표시도 달라 이 부분은 남은 차이로 기록한다. 전체 모션/원본 기능 동등성을 검증했다고 주장하지 않는다.
